# 守望先锋 钢琴工坊代码生成器 (Overwatch 2 Piano Workshop)

> **Rebuilt by ANB** · 专为《守望先锋2》玩家打造的极简、高稳定性纯前端音乐工坊代码生成器。  
> 纯浏览器本地离线运行，将任意 MIDI 音乐一键转化为可在游戏中自动演奏的工坊规则代码。

---

## ✨ 核心特性

- 🔒 **纯前端离线运行**：所有 MIDI 解析与数据压缩 100% 在玩家本地浏览器完成，零服务器依赖，毫秒级响应。
- 👻 **全自动幽灵演奏**：替身机器人默认全员隐形，呈现丝滑纯净的琴键自弹效果，房主随时可按键切换显隐。
- 🎼 **智能多轨编曲**：支持多音轨单独试听，提供「推荐还原 / 精简钢琴 / 全部音轨」三档编曲，自动跨轨去重与幽灵音过滤。
- 🎤 **字幕与歌词同步**：原生支持 MIDI 内嵌歌词及 `.lrc` 歌词文件，随乐谱速度自适应同步显示。
- 🇫🇷 **巴黎双机位切换**：预设**卢娜歌舞厅（点位 A）**与**贵族庄园（点位 B）**，完美契合观赏与视频录制。
- 📊 **工坊容量安全监控**：实时精确测算规则字符占用率，支持多首歌曲打包连弹，杜绝游戏内爆仓报错。

---

## 🎮 快速使用指南

1. **选择乐谱**：打开网页，从精选曲库选择曲目，或直接将你的 `.mid` 乐谱拖入网页。
2. **生成代码**：按需调整点位与编曲方案，点击 **【🚀 立即生成工坊代码】** 并复制。
3. **游戏导入**：
   - 进入《守望先锋2》：【自定比赛】->【创建比赛】->【设置】；
   - 点击右侧操作栏第二个图标 **【从剪贴板粘贴规则】**；
   - 进入地图（巴黎），走到钢琴前按 **F** 键即可开始演奏！

---

## ⌨️ 游戏内操作快捷键

| 按键组合 | 功能作用 |
| :--- | :--- |
| **`F`**（互动键） | 开始播放 / 暂停播放 |
| **`Ctrl`（蹲下）+ 鼠标左键** | 播放加速（+5%） |
| **`Ctrl`（蹲下）+ 鼠标右键** | 播放减速（-5%） |
| **`Ctrl`（蹲下）+ `R`（换弹）** | 重置进度，从头开始播放 |
| **`Ctrl`（蹲下）+ `V`（近战）** | 房主切换机器人显形 / 幽灵隐形 |

## 📁 项目结构

```text
ow-piano-web/
├── index.html              # 战术终端风格单页应用 (响应式/纯前端)
├── 双击打开网页.bat          # Windows 本地免服务器直接启动脚本
├── js/
│   ├── midi.min.js         # Tonejs/Midi 前端音频解析引擎
│   ├── owmidiparser.js     # 工坊数组生成与 7-bit 数据压缩核心
│   ├── workshopTemplate.js # 精简高稳定性工坊规则生成模板
│   └── app.js              # 网页交互控制与多轨播放器逻辑
├── midi_library/           # 预置精选曲库与歌词源文件
└── tools/                  # 曲库自动化打包与构建脚本
```

---

## 💡 曲库拓展与维护

如需往网页内置曲库添加新歌：
1. 将 `.mid`（及同名 `.lrc` 歌词）放入 `midi_library/<分类名称>/` 文件夹中；
2. 运行 `node tools/build-library.js` 即可自动打包入库。

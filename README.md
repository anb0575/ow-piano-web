   - 乐谱解压完成后自动销毁进度条，保持画面干净通透。

   - 地图规则内已默认将生成的替身机器人全员隐形，呈现丝滑纯净的幽灵琴键演奏。
   - 房主可在游戏内随时使用快捷键 `【蹲下 + V】` 自由切换机器人显形与隐形。

5. **完整快捷键操控系统**：
   - `【F / 互动键】`：开始播放 / 暂停播放
   - `【蹲下 Ctrl + 鼠标左键】`：加快播放速度（+5%）

## 🎼 内置曲库维护

内置曲库的数据来自 `midi_library/`：每个子文件夹就是一个分类。构建脚本会把全部 MIDI 转成 Base64，打包进 `js/samplesData.js`，网页离线也能秒载入。

**新增曲目**：把 `.mid` 文件放进 `midi_library/<分类>/`（新建文件夹就是新分类），然后运行：

```bash
node tools/build-library.js
```

**可选配置**写在 `tools/library.config.json`：

- `featured`：置顶的精选曲目及顺序
- `categoryOrder`：分类显示顺序
- `songs.<曲名>.artist`：歌手 / 作曲家
- `songs.<曲名>.keywords`：检索关键词，例如英文名、拼音、拼音首字母

没写配置的曲目也能正常收录，只是不显示歌手名，检索时只能按曲名和分类搜到。

### 🎤 游戏内字幕（歌词 / 背景介绍）

演奏时，屏幕下方会按乐谱时间逐条弹出字幕。字幕跟着乐谱走，调速后依然对得上。每首歌的字幕按以下优先级取一种：

1. **MIDI 内嵌歌词**：KAR 卡拉 OK 格式自带的歌词，和音符天然对齐，最准确。
2. **同名 `.lrc` 歌词文件**：
   - 曲库：放在 `midi_library/<分类>/` 中，与 `.mid` 同名，重新构建后生效。
   - 网页上传：与 MIDI 一起拖入即可自动配对。
   - LRC 的时间轴来自原唱录音，和 MIDI 可能有前后差距。可以在 `tools/library.config.json` 的 `songs.<曲名>.lrcOffset` 里用秒数校准，正数推后、负数提前。
3. **配置中的歌词**：`songs.<曲名>.lyrics`，格式为 `[[秒, "歌词"], ...]`，时间从第一个音符算起。
4. **背景介绍**：`songs.<曲名>.intro`，开场后逐条显示，适合纯音乐和钢琴曲。

### 🎹 音轨选择（编曲）

很多 MIDI 是整支乐队的编曲（吉他、贝斯、弦乐、合唱、铜管……）。机器人只有 10~11 个，但数量并不是瓶颈——整支乐队合并后 10 声部的还原度也在 98% 以上。每首歌有三档编曲：

- **推荐编曲（默认）= 钢琴上的最大还原**：保留全部有音高的乐器声部（旋律、和声、低音、对位、铺底），只去掉鼓 / 定音鼓 / 音效、重复声道、几乎没有音符的音轨。唯一的硬约束是机器人忙得过来：10 声部还原度低于 98.5% 时，才依次舍弃最不重要的音轨。**不考虑工坊容量**，容量由使用者自己取舍。
- **精简钢琴**：只留钢琴与旋律，最干净。
- **全部音轨**：全部原样合并（含重复声道、定音鼓等）。

合并时的清理（对所有档位生效）：
- 跨音轨去重：不同音轨在 45 毫秒内弹同一个音（如吉他与钢琴同奏旋律），只保留最早的，避免同一琴键被连敲两次。
- 过滤幽灵音：力度低于 0.05 的音在原曲里几乎听不见，放进游戏却是满音量。
- 和弦同一时刻的音多于声部数时：最低的两个音（低音线）与最高音（旋律）优先，其余按乐器重要性取舍（旋律乐器 > 贝斯 > 钢琴 > 吉他 > 弦乐合奏 / 铺底）。

手动调整：播放列表里每首多音轨歌曲都有「音轨 n/m」按钮，可逐条勾选，或一键切换三档。**每条音轨右边的 ▶ 可以单独试听**，用来找出哪一条声部听着不合适。工坊容量提示条（≥90% 时出现）上有可选的「精简编曲」按钮。

曲库里的歌默认用推荐编曲；如需手工指定，在 `tools/library.config.json` 的 `songs.<曲名>.tracks` 里写音轨序号，然后运行 `node tools/build-library.js`。
